# Dashboard Proyección Docente ETITC 2027-2035

Dashboard gerencial interactivo de la planta docente proyectada de la Escuela Tecnológica Instituto Técnico Central (ETITC) para el horizonte 2027-2035.

## 🔗 Ver dashboard en vivo
👉 **https://famaos08-stack.github.io/dashboard-proyeccion-docente-etitc/**

## 📊 Características principales

- **18 vigencias semestrales** proyectadas (2027-1 a 2035-2)
- **6 niveles académicos** (Técnico Profesional → Doctorado)
- **30 programas académicos** distribuidos en el portafolio institucional
- **Visualizaciones avanzadas** con Chart.js y ApexCharts
- **Filtros dinámicos** por vigencia y nivel académico
- **6 KPIs estratégicos** con tooltips explicativos
- **Diseño ejecutivo** con identidad corporativa ETITC
- **Matriz pivot interactiva** programa × vigencia con heatmap
- **Insights narrativos** que se recalculan en tiempo real

## 📈 Insights clave del horizonte

- **Crecimiento total:** De 661 docentes (2027-1) a 3.318 (2035-2) — **+402%**
- **CAGR anualizado:** ~21,2% de crecimiento compuesto sostenido
- **Nivel líder:** Profesional Universitario con 1.144 docentes al cierre
- **Programas estrella:** Ingeniería en Inteligencia Artificial (375) y Ciencia de Datos (349)
- **Viraje estratégico:** 7 de los 10 programas con mayor planta pertenecen al ecosistema IA

## 🚀 Cómo actualizar el dashboard

1. Descarga `index.html` del repositorio
2. Edita localmente el archivo (datos o estilos)
3. Sube los cambios:

```bash
git add index.html
git commit -m "Actualización: [descripción del cambio]"
git push origin main
```

Los cambios se publican automáticamente en 1-2 minutos en GitHub Pages.
